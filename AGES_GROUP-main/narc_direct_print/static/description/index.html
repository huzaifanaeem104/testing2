How It Works

Three Steps to Direct Printing

Configuration takes under a minute. No developer required.

1

Install the Module

Upload & install like any standard Odoo module. No external dependencies.

2

Open Your Report's Settings

Go to Settings → Technical → Reports and open the report you want (e.g. Invoices).

Settings → Technical → Reporting → Reports
3

Switch to "Open Print Dialog"

In the new Print tab, select Open Print Dialog. Save. Done.

✓

Print Directly from Any Record

Click the report from any record — your browser print dialog opens instantly, report loaded and ready.
